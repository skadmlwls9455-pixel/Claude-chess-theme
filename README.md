# Endgame

1-bit dithered chess look for Claude (desktop and mobile apps): black ground, ivory type, one hot red, and the board after …Nxg3!! as a backdrop. Dark mode only.

## Install

```
/plugin install endgame --marketplace skadmlwls9455-pixel/Claude-chess-theme
```

Turn off: `claude plugin disable endgame@claude-chess-theme`
